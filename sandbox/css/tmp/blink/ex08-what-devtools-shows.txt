=== Reading it ===
  #lead sets green with the highest specificity (1,0,0), so green wins
  even though .note { color: rebeccapurple } comes LATER in the file.
  This is what the Styles pane shows as struck-through declarations:
  every losing rule is still listed, in the order it was beaten.
  :where(.note) contributed letter-spacing at specificity 0,0,0 —
  it applied because nothing else set letter-spacing at all.
  text-indent came from the inline style attribute, which is why
  DevTools shows it in its own "element.style" block at the top.
