**★ `aggregate()` returns a cursor, not a promise.** Forgetting `.toArray()` and
`await`-ing the cursor gives you the cursor object, and `res.json(cursor)`
serialises an object with none of the data in it — a 200 with a shape nobody
expected.

**★ An unclamped date range is a full scan behind an admin cookie.** Every cost
in this chapter is proportional to the documents the leading `$match` selects,
and that is user input. Clamp the range in the route, and clamp any `n` before it
reaches a `$topN`.

**★ Set `comment` on every pipeline.** It is one string, it costs nothing, and it
is the difference between an operator seeing a stage array in `currentOp` and
seeing `admin:dashboard`. Nobody sets it until the first incident.
