# Vite — the link map

For every topic on the [Vite track](../README.md) — written or not — the primary documentation, plus where a good one exists a **Beyond the docs** pick: the best non-official explanation (article, blog, talk, repo) with one line on why it explains the concept differently.
Every link was fetched on the date beside it (2026-10-14). Vite has no syllabus file, so the topics are our pages: each numbered page and its chunks form one topic, and a page with many chunks gets one block per cluster of chunks. Written topics link to our own page.

**Reading a block.** **Read this** is the best primary page for the topic. **Also good** adds something the first lacks. **Beyond the docs** is the best non-official explanation found — omitted when none was good enough.
**Covers our angle** says whether it matches what our page promises — *full*, or *partial* and what is missing. **Our delta** is what our own page keeps saying that nobody else does.

**How far to trust a block.** *read* means the passage was read and the claim matches. *Headings only* means the page was fetched and its headings and size checked, but the passage was not read — treat that pick as a strong lead. Vite moved from Rollup and esbuild to Rolldown and Oxc in version 8: picks written for Vite 7 or earlier are flagged in their block. Each file was written by one agent and then attacked by a second; this is still a first pass and open for review.
