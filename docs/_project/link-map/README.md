# The link map

For every topic in our existing syllabus, written or not: the page on the internet that explains it best, one line
on why, and what it leaves out. Every link was fetched and read on the date beside it. Official docs get no
preference — a page wins on the explanation.

🔴 **Staging copy.** It lives here, outside the site build, until the user approves the format. Nothing here is
published and nothing in `docs/` was changed to make it. Rules, record format, resume point:
[../CURSOR-LINK-MAP.md](../CURSOR-LINK-MAP.md).

| Track | Files | State |
|---|---|---|
| Redux Toolkit — 21 topics, all written | [redux-toolkit/](redux-toolkit/) | pilot, in progress |

**Reading a block:** **Read this** is the best single page for the topic; **Also good** adds something the first lacks;
**covers our angle** says whether it matches what our syllabus row promises (*full*, or *partial* and what is missing);
**Our delta** is what our own page must keep saying; *Checked, not chosen* is an alternative I opened and why it lost.
A topic nobody explains well reads `Read this: none found` — that one is ours to own.
