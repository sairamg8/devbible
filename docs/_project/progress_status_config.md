## The file

`static/status.json`. Docusaurus copies `static/` to the site root, so the dashboard fetches
**`/devbible/status.json`** — no import, no bundler, no build step.

`version`, `generatedFrom`, `updated`, `totals`, then `languages` as a flat **array** — one
row per language, ready to `.map()` in a dashboard:

```json
{"key":"java","label":"Java","status":"in-progress","percent":69,"topics":232,
 "completed":160,"pending":72,"phases":"11/17","next":"11 · Testing",
 "docs":"/docs/java","updated":"2026-08-31 10:17","note":"Active — …"}
```

`status` is `complete` · `in-progress` · `not-started` · `parked` · `blocked`.
First generation, 2026-08-31: **27 languages · 20 complete · 4 in progress · 2 parked ·
1 blocked · 2,057 of 2,629 topics (78%)**.

## Derived vs hand-written — the whole design

🔴 **Every count is derived from `src/data/progress.js`** (still the one hand-maintained
source of truth) through its own `summarise()`. No second copy of a number to remember to
bump: a session updates its language's row there and re-runs the generator.

🔴 **Exactly two fields are hand-written, and regeneration preserves them:** `note`, and a
`status` of `parked` or `blocked` — the human decisions the counts cannot infer, which
otherwise live only as prose in `LOCKS.md`. That is why MongoDB (41%) and Nginx (22%) read
`parked` rather than `in-progress`, and Python (8%) reads `blocked`. Everything else is
overwritten on every run.

```bash
yarn status           # rewrite static/status.json
yarn status --check   # exit 1 if stale — CI / pre-commit
```

## Traps found while building it

- **`src/data/progress.js` is ESM in a CJS-default package**, so Node cannot `import()` it by
  path. The generator copies it to a temp `.mjs` and imports that — no transform, no dep.
- **`phaseStatus()` returns `written`/`writing`/`planned`/`parked`**, not the dashboard's
  `complete`/`in-progress`/`pending`. Comparing against the mapped names *before* mapping
  silently reported `completed: 0` on every finished phase. (Gone with the per-phase list in
  the simplified cut, but the same trap waits for anyone who adds it back.)
- **`updated` is the freshest per-language stamp, not a wall clock.** A build timestamp would
  churn the diff on every run and make `--check` useless.
- The **`.claude/worktrees/angular-dashboard`** worktree seen here was another session's,
  building the Angular syllabus and the homepage rebuild. Both it and this one were removed
  the same day. Nothing consumes `status.json` yet.
