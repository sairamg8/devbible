# devbible = the hub + the delta, not a re-explanation of free material

**Said 2026-09-14**, in four messages, one session:

> *"Majority of explanations everything already readily available from w3schools and what does devbible can do better ?"*

> *"my goal rather than writing all the explanation either with gotchas or anything what i need to add apart from what was there in w3schools especially how i can effectively use the both of them combination to learn PERN or MERN or any fullstack ? main goal is PERN and MERN and then java"*

> *"The goal should also consider various online resources gather in one place it need to identify the gaps that we can fill in devbible apart from existing content to useful"*

Earlier in the same session they framed the original intent: *"It was never creating a
alternative to w3schools but for me when i wish to pick something to learn i need to pick it
up with everything in one place rather than using any 3rd party"*.

**Why:** the user noticed that most of devbible's explanations restate what w3schools already
has. "Everything in one place" stays the goal, but now it means one place to **start from and
navigate by**: devbible links out to the best free page for the basics and spends its own
words on what those pages miss.

## How to apply

- **Priority order:** PERN and MERN first, then Java. DSA/system design support them. They
  don't compete with them.
- **Before writing a topic, check what the free resources already teach.** If w3schools or
  MDN or the official docs explain the concept well enough, devbible's page covers the
  **delta**: gotchas (symptom → cause → fix), internals, production and security concerns,
  cross-stack wiring, version currency, interview Q&A. It links to the external page for the
  basics.
- **Topics no free resource covers well get full devbible treatment.** They are devbible's
  real value.
- **The gap map is the research behind this:** [[research-external-resources-gap-20260914]].
  It records what w3schools and the other major free resources cover per track, the ranked
  gaps, and the pending topics classified EXT-BASICS / MENTION / ABSENT.
- 🔴 **This conflicts with `instructions.md` §5** ("Not a summary, not a pointer to the
  official docs — the actual explanation"). Until the user explicitly rules on the brief,
  **do not rewrite written pages and do not edit `instructions.md`**. Propose the brief change
  and let the user decide. See [[devbible-brief]], [[senior-roadmap-suggestions]].
- **Resume the research from [[cursor-free-resources-gap]]** (`CURSOR-FREE-RESOURCES-GAP.md`).
  It was paused 2026-09-14 with no results banked.
