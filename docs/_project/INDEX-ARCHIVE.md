- 🔴🔴 **[THE MDX RULE THAT BROKE THE DEPLOY FOR 3 DAYS + CLAUDE.md cut to rules-only — 2026-08-26](progress_session_20260826_java_p10_deploy_repair.md)** — **READ THIS BEFORE WRITING ANY DOCUSAURUS PAGE.** Every GitHub Pages deploy failed 2026-08-23 → 08-26 on **one character class**: a bare `<!-- -->` HTML comment in prose. **Docusaurus v3 parses `.md` as MDX, which has no HTML comments** — *"Unexpected character `!` (U+0021) before name"* aborts the client bundle. devbible's own `<!--CHUNKS-->` and `<!--FOOTER-->` scaffolding markers were the cause. **Use `{/* ... */}`**; inside a fenced block a comment is fine.
