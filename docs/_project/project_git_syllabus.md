## Measured facts — `sandbox/git-p0/ex1-version-facts.sh`

Runs in a `/tmp` throwaway repo with `GIT_CONFIG_GLOBAL=/dev/null` and
`GIT_CONFIG_SYSTEM=/dev/null`, so a measured default is **Git's** default and not
this laptop's. Output kept at `sandbox/git-p0/ex1-output.txt`.

| Fact | Value |
|---|---|
| Version | **git 2.55.0** |
| Commands | 46 main porcelain, **172** on `PATH` |
| **`git init` default branch** | **`master`** — hint says *"will change to `main` in Git 3.0"*. **The common claim that Git already defaults to `main` is FALSE on 2.55.0** |
| Object format | sha1 default; `--object-format=sha256` works |
| Ref backend | `files` default; **`reftable` supported**, writes `.git/reftable/tables.list` |
| Divergent pull | with `pull.rebase`/`pull.ff` unset → `fatal: Need to specify how to reconcile divergent branches` |
| `switch`/`restore` | no longer labelled experimental in usage output |
| New commands | `backfill`; **`replay` and `last-modified` self-label EXPERIMENTAL** |
| `scalar` | bundled, reports `git version 2.55.0` |
| **Absent** | **`git-filter-repo` and `git-lfs` are NOT installed** |
| Object model proof | `printf 'blob 6\0hello\n' \| sha1sum` = `ce013625…` = `git hash-object`. Empty blob `e69de29b…` |
