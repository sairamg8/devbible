**The ranked answer (kept for the record):** 1 system design track, HLD + LLD — the round that
sets the band · 2 DSA daily from now · 3 event streaming (Kafka, CDC, event sourcing) as a
track · 4 cloud + Kubernetes + IaC · 5 LLM features inside the PERN stack (the 2026
differentiator) · 6 API design and contracts (GraphQL, gRPC, tRPC, OpenAPI, contract tests) ·
7 reliability engineering (SLOs, error budgets, incidents, load and chaos testing) · 8 proof of
work (deployed project with real traffic, one merged OSS PR, public design write-ups). Order:
DSA immediately, system design syllabus next, then one capstone on eKommerce that exercises
Kafka + Kubernetes + one LLM feature. Keep Java going — it widens the company pool.
