# Job map — India (UI / Node MERN-PERN / Java Spring Boot)

Private tracker, kept out of the site build (`docs/_project/`). Created 2026-10-06.

**Status of the data — read first.** The company lists below come from general knowledge of who
typically hires these roles in India, *not* from a verified check of today's openings. A web
search only returned job-board aggregate counts (see "Live signals"), not per-company openings.
So: **a ✅ means "regularly hires this track, go check"; it does not mean "has an open role today".**
Tick the `Applied` column as you go and put the date in `Checked`.

Legend: **UI** = frontend / UI engineer (React, Angular, TS) · **Node** = Node/Express backend or MERN/PERN fullstack · **Java** = Spring Boot backend.
