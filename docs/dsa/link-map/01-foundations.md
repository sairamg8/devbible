# Link map · DSA · Part 1 (phases 0–2)

Covers every topic row of phases 0, 1 and 2 in `docs/dsa/syllabus/01-foundations.md`: the interview and practice system (T00-01 to T00-14), complexity analysis (T01-01 to T01-11) and recursion, maths and bits (T02-01 to T02-13). That is 38 rows, and each has a written page of ours (a chunked topic shows its first chunk file; many topics also continue in lettered chunks).
*read* = I read the passage that supports the claim in the fetched text; *headings only* = fetched at 200 and the headings or opening checked. Third-party links carry a date only where the page shows one. No `#anchors` are given. Where no good non-official explanation turned up after a second search, the block has no "Beyond the docs" line. "Official" means canonical references (cp-algorithms, Princeton algs4, MDN, the Java docs, Wikipedia for definitions). Phase 0 is process advice, so its picks are mostly interview-prep writing, and the claims in them are one author's view. Tier words are the tier badges in the syllabus tables, checked row by row (T00-04 and T01-07 are Master).
Things to know. LeetCode problem pages, the LeetCode discuss board, Codeforces blogs and some GitHub pages returned 403 to the fetcher, so no problem links are given. The Competitive Programmer's Handbook PDF and two lecture PDFs were downloaded and read as extracted text. cp-algorithms, MDN and the Java SE 25 docs were live on 2026-10-14. The language of each Beyond pick is noted (JavaScript, Python, Java, or language-neutral); our solutions are TypeScript first, Java second.
