# DSA — the link map

For every topic in the [DSA syllabus](../README.md) — written or not — the best canonical reference (cp-algorithms, Princeton Algorithms, MIT 6.006, Wikipedia for definitions), plus where a good one exists a **Beyond the docs** pick: the best explainer (article, blog, talk, repo) with one line on why it explains the concept differently.

**Reading a block.** **Read this** is the best canonical page for the topic. **Also good** adds something the first lacks. **Beyond the docs** is the best non-canonical explainer found — omitted when none was good enough.
**Covers our angle** says whether it matches what our syllabus row promises. **Our delta** is what our own page will need to say that nobody else does.

**How far to trust a block.** *read* means the passage was read and the claim matches. *Headings only* means the page was fetched and its headings checked, but the passage was not read. Interview-problem sites (LeetCode, Codeforces, GeeksforGeeks) often refuse scripted fetches and are linked only where they loaded. Each file was written by one agent and then attacked by a second; this is still a first pass and open for review.
