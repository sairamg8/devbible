# Storybook — the link map

For every topic on the [Storybook syllabus](../README.md) — written or not — the primary documentation, plus where a good one exists a **Beyond the docs** pick: the best non-official explanation (article, blog, talk, repo) with one line on why it explains the concept differently.
Every link was fetched on the date beside it (2026-10-14). Topics are the rows of the four syllabus files; topics our pages do not yet cover are marked 🔲 not written.

| File | Covers | Our page |
|---|---|---|
| [01-how-it-runs-and-composing.md](01-how-it-runs-and-composing.md) | Phases 0–5 · how Storybook runs, the story format, args, decorators, docs, theming | see each block |
| [02-testing-config-shipping.md](02-testing-config-shipping.md) | Phases 6–10 · interaction, accessibility and visual testing, configuration, shipping | see each block |

**Reading a block.** **Read this** is the best primary page for the topic. **Also good** adds something the first lacks. **Beyond the docs** is the best non-official explanation found — omitted when none was good enough.
**Covers our angle** says whether it matches what our page promises — *full*, or *partial* and what is missing. **Our delta** is what our own page keeps saying that nobody else does.

**How far to trust a block.** *read* means the passage was read and the claim matches. *Headings only* means the page was fetched and its headings and size checked, but the passage was not read — treat that pick as a strong lead. Each file was written by one agent and then attacked by a second; this is still a first pass and open for review.
