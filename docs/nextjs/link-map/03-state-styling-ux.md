# Link map · Next.js · Part 3 (chapters 8–10)

Covers every topic row of chapters 8, 9 and 10 in `docs/nextjs/syllabus/03-state-styling-ux.md`: state management in an RSC world (T08-01 to T08-06), styling and UI (T09-01 to T09-05), and forms, authentication and security hardening (T10-01 to T10-05). That is 16 rows, and every one has a written page of ours (a chunked topic shows its first chunk file). The three "Project Milestone" bullets (T08-07, T09-06, T10-06) are not topics and are skipped.
*read* = I read the passage that supports the claim; *headings only* = fetched at 200, headings or opening checked. Third-party links carry a date only where the page shows one. No `#anchors` are given. Where no good non-official explanation turned up after searching, the block has no "Beyond the docs" line. Two pages (react-hook-form.com and blog.mathpresso.com) refused a scripted fetch and are not linked.

🔴 **Version note.** Target is **Next.js 16.3, React 19.2**. Official links point at the current nextjs.org/docs App Router pages (the pages themselves carry `lastUpdated` stamps of 2026-03 to 2026-10 and were live on 2026-10-14). Some pages also carry a `version: 16.4.0` front-matter stamp; that is the docs build, not our target. Picks that predate Next 16 or the App Router are flagged in their block.
🔴 **Security note (chapter 9).** The syllabus carries a live correction: the August 2026 release (16.3.3 and 15.5.24) disabled AVIF optimization (GHSA-2xp9-vwfh-vxw4) after a libheif flaw reachable through `sharp`. The Image API reference still documents the `formats` option with AVIF, so do not treat that page as a recommendation to enable it. Source: [August 2026 Security Release](https://nextjs.org/blog/august-2026-security-release) · nextjs.org, 2026-08-25 · fetched 2026-10-14 (*read*).
