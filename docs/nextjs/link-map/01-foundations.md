# Link map · Next.js · Part 1 (chapters 1–3)

Covers every topic row of chapters 1, 2 and 3 in `docs/nextjs/syllabus/01-foundations.md`: introduction to Next.js (T01-01 to T01-07), routing and navigation (T02-01 to T02-08) and Server versus Client Components (T03-01 to T03-06). That is 21 rows; every one has a written page of ours (a chunked topic shows its first chunk file). Syllabus bullets that start with "Project Milestone" are not topics and are skipped (none occur in this part).
*read* = I read the passage that supports the claim; *headings only* = fetched at 200, headings or opening checked (after the second verification pass no pick in this part is left at headings only). Third-party links carry a date only where the page shows one. No `#anchors` are given. Where no good non-official explanation turned up after searching, the block has no "Beyond the docs" line.

🔴 **Version note.** Our pages were verified against **Next.js 16.3.4** (npm, 2026-08-31) and **React 19.2**. On 2026-10-14 npm `latest` is **16.4.0** (published 2026-10-06; 16.3.8 followed on 2026-09-30), and the live docs are ahead of us: the Server and Client Boundary guide's front matter reads `version: 16.4.0`, and the other pages fetched show `lastUpdated` dates from 2026-06 to 2026-10. The concepts below are unchanged. Two official pages still carry old text: the Pages-to-App migration guide is written for Next 13 (Node 18.17), and the Parallel Routes page still says a missing `default.js` renders a 404, which the version 16 upgrade guide overrides (builds fail). Every official link below is the unversioned current URL. Third-party picks are flagged where they predate 16.
