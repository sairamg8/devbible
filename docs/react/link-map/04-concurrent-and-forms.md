# Link map · React · Part 4 (phases 8–9)

Covers every topic row of `docs/react/syllabus/03-concurrent-and-server.md` in phase 8 (T08-01 to T08-18, concurrent rendering, Suspense and transitions) and phase 9 (T09-01 to T09-14, forms, Actions and optimistic UI). That is 32 rows, and all 32 have a written page of ours.
*read* = I read the passage that supports the claim; *headings only* = fetched, headings and size checked, claim not checked against the body. Third-party links carry a date where the page shows one. No `#anchors` are given. Second pass 2026-10-13: every URL was re-fetched (status 200, canonical address), each pick's claim was checked against the page body, and almost every react.dev page marked *headings only* was upgraded to *read*.

🔴 **Version note.** Our syllabus targets **React 19.2.8** (`docs/react/README.md`). react.dev on 2026-10-13 already documents **React 19.3** (blog post dated 2026-09-09): it says `ViewTransition` is stable in 19.3, and the `ViewTransition` reference page no longer carries an experimental banner. Our T08-17 row says "experimental only; not in 19.2.8", which is true for 19.2.8 but is now stale against the live docs. Flag for the currency sweep. The `ViewTransition` page's own sandboxes pin `19.3.0-canary-...` builds (only the Suspense example pins `19.3.0`), and the 19.3 post also says `ViewTransition` works only in the DOM and that React now fires `onReset` after an automatic form reset. `SuspenseList` has no page on react.dev (the reference URL returns 404), so T08-18 links the React source change instead. `requestFormReset` also has no reference page at the expected URL (404), so T09-09 cites the form reference, the React 19 post and the React pull request. `useFormState` links redirect to the `useActionState` page.
