**Reading a block.** **Read this** is the best primary page for the topic. **Also good** adds something the first lacks. **Beyond the docs** is the best non-official explanation found — omitted when none was good enough.
**Covers our angle** says whether it matches what our syllabus row promises — *full*, or *partial* and what is missing. **Our delta** is what our own page keeps saying that nobody else does.

**How far to trust a block.** *read* means the passage was read and the claim matches. *Headings only* means the page was fetched and its headings and size checked, but the passage was not read — treat that pick as a strong lead. Each file was written by one agent and then attacked by a second; this is still a first pass and open for review.
