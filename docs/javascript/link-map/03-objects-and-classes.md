# Link map · JavaScript · Part 3 (phases 4)

Covers every topic row of `docs/javascript/syllabus/01-language-core.md` in phase 4 (T04-01 to T04-20, objects, prototypes and classes). That is 20 rows, and all 20 have a written page of ours. Directory topics point at their first chunk file.
*read* = I read the passage that supports the claim; *headings only* = fetched, headings/size checked. Third-party links carry a date only where the page shows one. No `#anchors` are given. Where no good non-official explanation turned up after searching, the block has no Beyond line (T04-02 is the only such block).

🔴 **Version note.** Our syllabus verifies output in **Node 24 LTS** (`docs/javascript/README.md`). MDN tracks the current language. Several third-party picks are older than the language features they discuss and are flagged by date: the Philip Walton private-members post (2014) predates `#private` fields entirely, the V8 fast-properties post (2017) describes the engine at that time, the David Walsh `Object.create(null)` post (2017) predates `Object.hasOwn`, the Dmitri Pavlutin existence-check post (2023) also predates `Object.hasOwn` and does not cover it, the Pavlutin classes guide (2019) still lists private methods and static fields as proposals, and the javascript.info pages are dated 2021 to 2025 and can lag the newest syntax. `Error.isError` (T04-13) is new and not available in every engine: check support before relying on it.
